여러 이미지나 카드 후보를 한눈에 비교하고, 점수·판정·분류·메모를 기록하는 로컬 리뷰 도구입니다. 이미지와 평가 정보는 외부 서버로 전송되지 않습니다.

3분 빠른 시작

  1. 프로젝트 유형을 선택하세요.
    사진·일러스트는 ‘일반 이미지·사진 리뷰’, 타로와 카드는 ‘타로·카드 덱’을 선택합니다.
  2. 이미지나 폴더를 추가하세요.
    점선 영역을 클릭하거나 파일·폴더를 끌어놓습니다. 하위 폴더도 함께 읽습니다.
  3. 이미지를 평가하세요.
    별을 누르거나 연필 버튼에서 선정·보류·제외, 분류와 메모를 기록합니다.
  4. 비교하고 저장하세요.
    체크박스로 후보를 선택해 비교하고, 평가 데이터 또는 현재 보기를 저장합니다.

원본은 안전합니다. ‘목록에서 제거’와 ‘전체 지우기’는 브라우저의 현재 목록만 정리하며 PC의 원본 파일을 삭제하지 않습니다.

프로젝트와 보기 방식

일반 이미지·사진 리뷰는 다양한 비율과 2~8열 갤러리를 지원합니다. 타로·카드 덱은 세로형 기본값과 한 줄 2~6장 후보 비교를 제공합니다.

‘원본 비율’은 실제 비율을 유지합니다. ‘전체 표시’는 자르지 않고, ‘영역 채우기’는 빈 공간을 줄이는 대신 가장자리가 일부 잘릴 수 있습니다.

평가하고 후보 선택하기

  • 별점: 1~5점 기록
  • 연필 버튼: 선정·보류·제외, 분류와 메모 저장
  • 체크박스: 여러 이미지를 선택해 하단 일괄 작업 사용
  • 목록에서 제거: 현재 목록에서만 제거하며 원본 파일은 유지

‘선정’은 최종 후보, ‘보류’는 다시 볼 후보, ‘제외’는 낮은 우선순위로 구분할 때 사용하세요.

비교와 확대 보기

‘이미지 비교/후보 비교’는 정해진 레이아웃으로 후보를 비교합니다. 체크박스로 고른 뒤 ‘선택 항목 비교’를 누르면 선택한 후보만 볼 수 있습니다.

  • 이미지를 클릭하면 크게 열립니다.
  • ← → 또는 양쪽 버튼으로 이전·다음 이미지를 봅니다.
  • 확대창이나 미니맵 위에서 휠을 굴리거나 키보드 + −로 연속 확대·축소합니다.
  • 표시되는 확대율은 원본 이미지 픽셀 크기를 기준으로 합니다.
  • 본 이미지 위 휠은 포인터 위치를, 미니맵 위 휠은 현재 보이는 영역의 중심을 기준으로 확대합니다.
  • 확대 상태에서 마우스로 끌거나 우측 상단 미니맵을 클릭·드래그해 위치를 이동합니다.
  • 0은 원본 100%, F는 화면 맞춤으로 전환하고 Esc는 확대 창을 닫습니다.

확대 창이 열려 있는 동안 배경 페이지는 고정되어 휠 조작이 메인 화면으로 전달되지 않습니다.

저장과 평가 데이터

‘현재 보기 PNG 저장’은 현재 정렬·필터·배치를 한 장의 이미지로 만듭니다. 1×·2×·3×는 출력 해상도이며 원본 화질을 개선하는 기능은 아닙니다.

평가 데이터는 JSON으로 저장됩니다. 같은 이름의 이미지들을 불러온 뒤 가져오면 점수·판정·분류·메모가 연결됩니다.

키보드와 접근성

  • Tab / Shift+Tab: 다음·이전 요소
  • Enter / Space: 실행·선택
  • ← / →: 이전·다음 이미지
  • Esc: 열린 창 닫기

상단에서 기본·색각 보정·고대비 모드를 선택할 수 있습니다.

전체 지우기 · 메모리 비우기

현재 목록, 평가, 확대·비교 미리보기와 임시 이미지 메모리를 정리합니다. 원본 파일과 저장된 화면 설정은 삭제되지 않습니다.

자주 묻는 문제

폴더가 추가되지 않아요

Chrome에서 폴더를 끌어놓거나 ‘폴더 추가’를 사용하세요. PNG, JPG, WebP만 지원합니다.

평가 데이터 일부가 연결되지 않아요

파일 이름이 내보낼 때와 같아야 합니다.

Compare images or card candidates, then record ratings, decisions, categories, and notes locally in your browser.

3-minute quick start

  1. Choose a project. General Image · Photo Review or Tarot · Card Deck.
  2. Add images or a folder. Click or drag onto the dashed area.
  3. Review. Use stars or the pencil editor.
  4. Compare and save. Select candidates, compare, then export.

Projects and views

General review supports mixed ratios and 2–8 gallery columns. Card Deck uses portrait defaults and compares 2–6 cards in one row. Show all avoids cropping; Fill frame may crop edges.

Review and selection

Stars store ratings. The pencil editor stores Pick, Hold, Reject, category, and notes. Checkboxes enable batch actions. Remove from list never deletes original files.

Compare and zoom

Click to enlarge. Use ← → to navigate and the mouse wheel or + − to zoom continuously. The displayed percentage is measured against the image's original pixel size. Wheel over the main image to zoom around the pointer, or over the minimap to zoom around the current view center. Drag the image or click/drag the minimap to pan. Press 0 for true 100%, F to fit, and Esc to close. The background page stays locked while the viewer is open.

Save and review data

Save current view exports the layout as PNG. Export review data stores ratings and notes as JSON; import it after loading files with the same names.

Keyboard and accessibility

Tab moves focus, Enter/Space activates, arrows navigate, and Esc closes dialogs. Default, Color correction, and High contrast are available.

Clear all & release memory

Releases the current list, reviews, previews, and temporary URLs. Original files and saved display settings remain safe.
