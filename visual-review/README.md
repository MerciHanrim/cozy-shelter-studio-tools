# Cozy Shelter · Visual Review

A single-file, browser-only tool for reviewing, scoring, and comparing batches of images — built for picking favorites out of a large set (photo shoots, generated art, card decks) without leaving the browser. Nothing is uploaded anywhere.

**[Download `Cozy_Shelter_Visual_Review_v2.1.10.html`](Cozy_Shelter_Visual_Review_v2.1.10.html)** and open it in any modern browser (Chrome, Edge, Firefox). No install, no build step.

## Features

- **Project types** — General Image / Photo Review, or Tarot / Card Deck
- **Add images** — click or drag files/folders onto the drop area
- **Review** — rate with stars or annotate with the pencil editor
- **Compare and export** — select candidates, compare them side by side, then export
- **Save the current view as PNG** at 1×/2×/3× output resolution (this changes export resolution only — it does not enhance the original image quality)
- **Evaluation data as JSON** — save your scores, verdicts, categories, and notes; re-importing and loading images with matching filenames reconnects everything
- **Keyboard navigation** — Tab / Shift+Tab (next/previous element), Enter / Space (activate), ← / → (previous/next image), Esc (close dialog)
- **Accessibility** — default / color-vision-adjusted / high-contrast display modes
- **Korean / English** UI toggle

## Privacy

All processing happens in-browser. No image or evaluation data is ever sent to a server.
