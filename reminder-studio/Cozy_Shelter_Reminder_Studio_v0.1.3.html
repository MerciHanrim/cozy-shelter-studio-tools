선택 기능

기본 문구만으로도 모든 기능을 사용할 수 있어요.

이 기능을 켜면 문구를 새로 만들 때마다 브라우저가 위에서 선택한 제공사(Claude 등)로 직접 요청을 보내요. 이 툴은 서버 없이 파일 하나로 브라우저에서 동작해서, 그 과정에서 저희가 데이터를 볼 수 있는 경로 자체가 없어요. API 키는 이 브라우저에만 저장되고, 끄면 항상 무료 고정 문구만 사용해요.

등록한 일정은 이 브라우저에만 저장돼요. 다른 기기로 옮기거나 브라우저 데이터가 지워질 상황을 대비해 미리 내보내두세요.

제작 및 프로젝트 Cozy Shelter ↗

개인정보 처리 방식

가져온 CSV와 입력한 항목은 전부 이 브라우저의 localStorage에만 저장되며, 어디로도 전송되지 않습니다. "매일 자동 확인"을 쓰고 싶다면 위쪽 사용 가이드의 "매일 자동 확인" 항목을 참고하세요 — 이 파일을 매일 정해진 시각에 브라우저로 열어주는 설정입니다.

유일한 예외: AI 개인화 기능

설정에서 "AI로 매번 다른 문구 생성"을 켜고 본인의 API 키를 입력하면, 문구를 만들 때마다 선택한 제공사(Claude, OpenAI, Gemini, Grok 중 하나)로 브라우저가 직접 요청을 보냅니다. 이 툴은 애초에 서버 없이 파일 하나로 브라우저에서 동작하기 때문에, 저희가 그 데이터를 중간에서 볼 수 있는 경로 자체가 없어요. 이 저장소의 다른 툴들과 달리 이 기능만 네트워크를 사용하며, 끄면 항상 무료 고정 문구만 사용됩니다. API 키는 이 브라우저에만 저장됩니다.

음력 생일 계산 데이터 출처

음력 생일의 다음 발생일 계산(1900~2050년)에는 한국천문연구원(KASI)의 음양력 계산 데이터를 가공한 urstory/manseryeok-js(MIT License)에서 추출한 변환 테이블을 사용합니다. 원본 라이브러리를 그대로 포함하지 않고, 필요한 데이터만 이 파일 안에 직접 담았습니다.
