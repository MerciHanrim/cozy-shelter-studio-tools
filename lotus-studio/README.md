# Cozy Shelter · Lotus Studio

A single-file, browser-only mind-mapping tool built around the **Lotus Blossom Brainstorming** technique — expanding one central idea into eight surrounding themes, each of which can bloom into eight sub-ideas of its own. Nothing is uploaded anywhere.

**[Download `Cozy_Shelter_Lotus_Studio_v0.6.24.html`](Cozy_Shelter_Lotus_Studio_v0.6.24.html)** and open it in any modern browser (Chrome, Edge, Firefox). No install, no build step.

## Features

- **Three views** — Grid, Separated, and Mindmap, for different stages of brainstorming and presentation
- **Canvas navigation** — zoom with the mouse wheel or +/− buttons, drag empty space or a cell to pan, hold <kbd>Space</kbd> to drag without editing a cell, press <kbd>F</kbd> or use Fit to reset scale/position to the full structure
- **Fullscreen mode** enlarges just the workspace
- **Save / load as JSON** to continue a session later
- **Export** — Markdown (export or copy), CSV, PNG, and print-ready A4/A3 or PDF
- **Korean / English** UI toggle

## Privacy

All processing happens in-browser. No project data is ever sent to a server.
